# pairwise-ies-profile

路灯的光斑在地面拉出一条长椭圆，IES 文件里的坎德拉值被当成亮度直接乘，距离衰减算了两次；垂直角从 nadir 起算，代码按 zenith 起算，光斑上下颠倒；水平角在 0/360 接缝处插值跳变，环形对称的灯出现一道暗缝；光度网只存了半个平面，另一半按镜像补齐时符号取错；灯具旋转后 IES 的水平角没跟着转，光斑方向偏 90 度；强度单位是千坎德拉，导入时没换算，整条街过曝；归一化按峰值做，窄光束灯的总光通量被严重低估；阴影与 IES 衰减用了两套距离，近处地面出现双倍暗环；纹理图集把多盏灯的剖面塞在一张图，采样时 v 坐标没加偏移；远距离用低级别 mip，光斑边缘的截止角被抹平。render/ies_profile.py 是核心，tests/test_ies_profile.py 15个红。要修的是：坎德拉与亮度分离；角度基准统一；接缝环绕插值；补齐镜像符号；随灯旋转；单位换算；按光通量归一；衰减统一；图集偏移；mip 保留截止。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
